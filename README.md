# 🛡️ 究極個人認証システム「SHINOBI」

SHINOBIは、Windows 11 Pro環境において、OSの標準デスクトップを秘匿し、多要素認証（MFA）を強制する究極のセキュリティシステムです。
あなたのPCを「本人以外にはただの文鎮」に変え、かつ「本人がいる間は最高に快適」にします。

## 📋 機能一覧

### 1. 多層防御レイヤー
*   **物理層:** BitLocker (TPM 2.0) と連携し、ドライブ全体を暗号化。
*   **OS層:** `explorer.exe` を停止させ、本プログラムをシェル化。ログイン後、認証をパスするまでデスクトップを表示させません。
*   **権限層:** ロック中、タスクマネージャー、Win+L、ログアウト等をレジストリレベルで動的に無効化。
*   **監視層:** 低レベルキーボードフックにより、Alt+TabやAlt+F4による回避を封鎖。

### 2. インテリジェントMFA（5大解錠ルート）
| ルート | 認証要素 | ユースケース |
|---|---|---|
| **ステルス** | 顔認証 ＋ スマホ接近 | PCの前に座るだけで自動解錠。 |
| **ハイブリッド** | PIN入力 ＋ スマホ接近 | 暗所やマスク着用時。 |
| **ブラウザ鍵** | スマホ指紋認証 ⇒ BLE送信 | スマホを操作して確実に開ける。 |
| **W認証** | 顔認証 ＋ PIN入力 | スマホを忘れた際の二要素認証。 |
| **救済登録** | PIN入力 ＋ 顔写真保存 | 緊急用。証拠写真を残して解錠。 |

### 3. スマート緩和プロトコル
*   **1時間ルール:** 最後の解錠から1時間以内であれば、1要素（顔 or BT or PIN）のみで即復帰可能。
*   **心拍監視 (Heartbeat):** 10分おきにBluetooth RSSIを測定。スマホが離れた（電波強度が基準値を下回った）瞬間に、即座に「厳格モード」へ格上げし、再認証を要求します。

### 4. 証拠保全 (Audit Log)
*   過去7日間のログイン履歴と、解錠時の顔写真を全て保存。
*   8日前のデータは自動的にクリーンアップ。

## 🚀 使い方

### 1. セットアップ
1.  Python 3.10+ をインストールします。
2.  必要なライブラリをインストールします：
    ```bash
    pip install -r requirements.txt
    ```
3.  管理者権限で実行し、PINと顔データの初期設定を行います。

### 2. 起動とロック
*   システムの「シェル」として登録する場合、`os_control.py` を介してレジストリを書き換えます（管理者権限必須）。
*   通常起動時は `python SHINOBI/src/main.py` でロック画面が立ち上がります。

### 3. 管理者設定
*   解錠後、ダッシュボードから以下の設定が可能です：
    *   Bluetooth接近判定の閾値（dBm単位）
    *   顔認証の厳格度（しきい値）
    *   過去の監査ログの確認

## 🆘 緊急時のリカバリ
本システムは物理キーを排除しています。万が一ソフトウェアの不具合で解錠できなくなった場合は、以下の手順で復旧してください。
1.  PCをセーフモードで起動。
2.  レジストリ `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon\Shell` を `explorer.exe` に書き戻す。
3.  BitLockerの回復キーが必要になる場合があるため、回復キーは必ず物理的に（紙等で）別保管しておいてください。
